# 自适应导航、材质与原型：从看起来正确到动作可验证

分类：方法为 `TEAM_RECOMMENDATION`；界面、命名与状态选择为原创合成的 `PROJECT_CHOICE`。本文没有真实设计文件、项目标识、设备尺寸、材质参数或产品实测结论。所有待执行项保持 `NOT_RUN`，不能把实践中得到的方法直接换成此合成案例的通过成绩。

适用于已批准界面向其他窗口形态适配，或整理其主题、组件和原型。对应 [03 交接](../docs/03-figma-handoff.md)、[04 设计系统](../docs/04-design-systems.md)、[05 Apple](../docs/05-apple.md)、[08 验收](../docs/08-implementation-acceptance.md)及现有 [验收模板](../templates/verification-record.md)。其他平台采用通用检查方法，不照搬 Apple 的栏位置或材质。

## 合成任务

一款阅读应用有资料库列表、插画详情、编辑表单、同步设置和若干确认弹层。宽窗口中列表与详情并列，紧凑窗口中逐级进入。项目允许将部分导航移到侧边，保留列表局部操作、当前条目、编辑草稿和阅读位置；背景可按批准构图延展。既有主题与组件继续复用，不能为适配更换字体或改写正文。

原稿同时包含连接完整的流程、只有状态画面的页面和隐藏探索稿。它们不是同一种证据。合成任务先记录批准的源版本、当前候选和支持范围，再把待修改入口映射到现有目的地与状态。未说明的同步成功、错误恢复和表单提交结果属于设计缺口，不由连线工具自动决定。

## 问题、处理与反例

下表是可推演的失败机制与检查方法，不是实际发生的缺陷记录。

| 可能的问题 | 处理方法 | 不应误改的情况 |
| --- | --- | --- |
| 侧边增加返回后，旧页头还保留相同入口 | 确认对象与动作相同，再收起旧入口；读回可见性并看画面 | 列表添加与详情返回作用不同，不能一起删除 |
| 图层仍名为“返回”，图形和用途已改成删除 | 看实际图形、父级语义、文本与连接，建立操作映射 | 名称是线索，不是业务契约 |
| 规则把侧栏中所有文字都判为标签 | 分开栏目标签、状态徽标、菜单和辅助名称 | 数字徽标及未显示的辅助名称可以保留 |
| 把标题与符号的建议套给所有工具栏项 | 在适用的 Apple 工具栏场景区分纯文本与非纯文本项；非纯文本项同时提供标题和符号 | 合法纯文本项不被强制增加图标；隐藏视觉文字不删除菜单文字或辅助语义 |
| 外层无效果，误以为没有玻璃材质 | 深入实际承载层，检查已有效果和合成关系，再决定复用或补充 | 不在已有材质外重复叠加效果 |
| 效果存在，但填充重新变成不透明或绑定改变 | 核对最终解析值、模式和覆盖；对比真实背景上的画面 | 同名 token 或相同 RGB 不证明最终合成一致 |
| 已复制本地母组件，页面实例却仍引用外部来源 | 建立新旧组件映射，核对嵌套依赖、变体和覆盖，再验证消费者 | 不拆散实例伪装迁移完成；受阻字体保留身份，不静默替换 |
| 设置坐标后，自动布局把按钮挤到系统区域 | 写后读取父、按钮和图标几何，再按布局职责修正约束 | 不把所有子节点改为绝对定位以绕过布局 |
| 外框可点，中心图标仍执行失效的旧交互 | 分层检查实例连接、触发方式和遮挡；实点中心及相关区域 | 有效的组件变体切换不应批量删除 |
| 将复合控件中有意不同的动作都判为子层截获 | 先按语义操作划分热区，再分别核对独立子控件的契约与触发结果 | 列表行打开详情、行内收藏按钮切换收藏可以是两个独立操作，不为通过检查而统一连接 |
| 有目标 ID，但原型不能进入或进入错误条目 | 验证动作类型、目标能力、对象/形态/状态，再播放原型 | 不能只检查目标存在，也不要求统一重组所有 Frame |
| 填背景时连人物、文字一起放大，或生成主题图改变了构图 | 分开背景与前景；只修改批准的变化，并逐项对照原图 | 有意留白、剧情插画或不获准修改的素材保留 |
| 结构扫描无异常便写“全部验收通过” | 分开结构分母、可见画面样本和实际路径，列出未覆盖项 | 原型或真机没有执行，继续记 NOT_RUN |

## 从状态画面到明确路径

为每个受影响动作填写：来源页与业务对象、触发入口、动作类别、可用目标、应保留状态、可取消/返回路径及证据。名称相似的画面仅作为候选，需核对内容和适用条件。

例如，列表的新增入口仍属于列表，详情返回仍属于详情。删除入口进入原稿已批准的确认状态，取消应回到原条目和约定阅读位置。确认后的结果若缺少批准依据，则记录该缺口；不能因为恰好有空列表画面，就把“删除一个条目”连成“全部条目消失”。

同步目标变更同样区分取消、处理中、明确成功、明确失败和结果未知；原先关联何时解除、新关联何时生效由产品契约决定。异常时可返回哪里、是否允许重试、是否保留旧关联都需依据，不通过固定延时成功或重置表单制造闭环。

原型可以演示已批准的 fixture，但不具备真实保存、支付、系统授权或服务确认能力时，必须说明边界。从中间状态直接启动的检查单独标记；不能把没有前序可返回的问题掩盖为任意首页跳转，也不能以重新启动原型代替返回验证。

## 修改与恢复顺序

1. 确定当前可见范围、隐藏历史层、组件消费者及获准例外，定位源、目标和保护对象。
2. 读实际属性和嵌套关系。主题整理记录旧/新标识与解析值；材质先确认承载层；图片先分离背景、前景和可操作区域的职责。
3. 保留所改属性前值、节点身份和创建/移动关系，按可恢复范围执行。调整交接组织只为解决已验证的问题，不设“所有外框都转换”的规则。
4. 读回实际几何、绑定、模式、效果和原型动作，查看代表画面；在已知渲染完成后判断缺失或遮挡，随后实点受影响路径和相邻状态。
5. 如果调用结果不完整，先确认是否提交或回滚。未知时核对实际状态，不能因输出截断重新创建同一组对象。保留恢复记录到约定验收节点，按授权和使用情况清理临时对象，不能靠隐藏副本无限累积。

以上是设计方法，不是具体工具脚本；API、提交状态和导出限制在每次执行时核实。

## 待执行验收

实际采用时按项目风险拆分输入与状态子项。以下均没有运行证据，不要求所有项目采用同一支持矩阵。

| 编号 | 前置与动作 | 预期与证据 | 当前结论 |
| --- | --- | --- | --- |
| N01 | 对照批准原稿和候选，逐项查看迁移控件的图形、对象、用途和动作；比对迁移前后入口 | 真重复被处理，不同内容区操作保留；未确认语义列为缺口 | NOT_RUN |
| N02 | 对支持的侧栏/普通页头形态检查栏目标签、徽标、菜单及辅助名称，并执行适用的辅助输入；在适用的 Apple 工具栏场景分别核对纯文本与非纯文本项 | 视觉表示符合批准方案，徽标不被误删，辅助名称与实际动作一致；非纯文本工具栏项有标题和符号，合法纯文本项不被强制增加图标；仅隐藏文字不足以通过 | NOT_RUN |
| N03 | 查看实际材质承载层和全部相关嵌套效果；在批准主题、背景与适用系统设置下观察 | 无无意重复效果，最终对比与层级符合要求；效果名不能替代画面和平台证据 | NOT_RUN |
| N04 | 记录并迁移获准的变量或组件引用，读回别名、模式、覆盖、解析值和实际母组件；进行获准的主题往返并恢复 | 消费者、绑定、组件依赖与冻结外观保留；仅供参考的记录与真实消费者区分，旧来源不被过早删除 | NOT_RUN |
| N05 | 完成布局后读回父、按钮、图标几何；检查视觉中心、热区与相邻系统区域 | 没有被自动布局重新挤走，旧内边距不造成偏移，点击区域不遮挡其他操作 | NOT_RUN |
| N06 | 按语义操作划分热区，在原型中分别激活同一操作的图标中心、文字及获准留白；独立子控件按各自契约激活，并执行适用的键盘/辅助路径 | 同一语义操作内的声明有效区域命中该操作；独立子控件分别命中各自动作，互不误触或截获；旧连接不截获，合法变体行为保留 | NOT_RUN |
| N07 | 核对导航/浮层/变体动作与目标能力后，从入口进入各适用状态，再直接启动选定中间状态作对照 | 对象、形态、状态和前序正确；缺少前序、空目标和不支持的目标明确暴露，不任意回首页 | NOT_RUN |
| N08 | 进入详情或确认状态后取消/返回；在选择、草稿和滚动改变后重复相关路径 | 恢复约定的对象与任务状态；属性读回和重启原型不代替实际返回 | NOT_RUN |
| N09 | 按批准 fixture 分别执行同步目标变更的取消、处理、成功、失败及未知结果路径；执行各自获准的恢复操作，并逐条标注 fixture／原型证据及后台验证状态 | 旧/新关联的生效条件和恢复前提符合契约；模拟的成功、失败和未知结果均不证明真实后台行为，后台另有实际证据前保持未验证；未演示或缺失的适用分支不得汇总为通过 | NOT_RUN |
| N10 | 对照原图与候选，检查背景覆盖、前景几何、裁剪与获准主题变化；查看边缘及系统栏下方 | 构图、风格、人物/物件及信息用途按约定保留；延展、遮罩与操作安全区分别成立 | NOT_RUN |
| N11 | 在隔离且获准的范围，用有明确提交状态或受控未知结果的工具场景检查恢复；确认渲染就绪再比较导出 | 能判断读回还是安全重试，不重复创建；暂未加载与真实缺陷不混淆，原始证据保留 | NOT_RUN |
| N12 | 逐项对照目标清单、结构结果、画面样本、操作记录和修改后的相关复验 | 各层覆盖分母、版本、例外与未做项一致；父项不跨过未满足的必需子项 | NOT_RUN |

## 交付边界

交付包括问题与影响、修改理由、最终差异、验证分层及恢复入口，不以修改节点总数代替收益或通过率。实际项目数据留在项目获准位置；本公开示例不收录源图、私有节点、参数或截图。作者内容走查、独立审阅、用户确认和真实产品验收分别记录，旧案例的通过或未执行状态不因本文新增而改变。
