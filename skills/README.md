# 设计技能目录

状态：`0.1.0-draft.2` / `REVIEW_CANDIDATE`。这里是技能的创作与审阅目录，不是已安装清单或正式技能发行包。

## 本仓库新增的原创技能

| 入口 | 解决的问题 | 不负责的事 |
| --- | --- | --- |
| [design-direction-review](design-direction-review/SKILL.md) | 从受众、任务、品牌与实际证据判断视觉层级、设计语言和候选方向；区分可用性问题、视觉不一致和审美偏好 | 不自动重做已批准设计，不代替正式无障碍审计，不把建议当实现 |
| [adaptive-ui-review](adaptive-ui-review/SKILL.md) | 审阅窗口、内容与输入变化时的布局、导航和状态连续性，给出针对性验证计划 | 不自动迁移 SDK、修改构建配置或操作设备，不凭截图签署运行通过 |

两个技能都是本仓库原创方法，不是从第三方插件或 SDK 导出的文件。它们没有脚本、MCP 依赖、模型设置或自动委派要求；单独的技能文件夹包含其所需本地说明，不依赖私人路径、账户或笔记。原创内容的许可仍依 [许可说明](../LICENSE-NOTICE.md) 待定，元数据也保留该状态。

## 已有能力的复用边界

2026-10-26 的定向盘点核对了以下技能入口与部分许可文件；没有逐条审计所有附属资料，也没有运行它们。版本只说明本次看到的安装包，不代表最新版本、完整兼容性或效果认证。

| 能力 | 所见入口 / 版本 | 复用方式与限制 |
| --- | --- | --- |
| Web 视觉方向与风格 | Taste 插件 `2.0.0`：`design-taste-frontend`、风格专用技能 | 主入口明确偏向落地页、作品集与改版，并排除 dashboard、数据表格和多步骤产品 UI；不能作为所有界面的统一规则。所读包级与 taste 组件许可为 MIT，但本仓库未复制内容；将来引入时仍需逐项核对组件来源与署名 |
| Web 界面工程 | 同包 `frontend-ui-engineering` | 可用于 Web 组件、交互和响应式实现；与审阅方法互补，不等于原生平台实现能力 |
| Figma 操作与交接 | Figma 插件 `16.0.0`：`figma-use`、`figma-generate-library`、`figma-design-to-code`、`figma-swiftui` 等 | 保持由对应插件提供实际操作流程；账号访问、可用工具与当前版本另行核对。未建立这些技能文件可独立再分发的许可依据，不镜像 |
| Apple 实现与窗口适配 | `swiftui-specialist`、`swiftui-whats-new-27`、`app-resizability` | 仅在目标 SDK、系统与任务适用时读取；实现迁移入口不等于只读设计审查。未核定导出文件的再分发许可，不收入本仓库 |
| 运行验证 | `device-interaction` | 可作为目标环境提供的验收能力；其操作、委派和独占会话前提须按实际宿主另行确认，不成为本仓库通用要求 |
| 字体准备 | `font-fetch` | 属于本机工具适配；可找到字体不等于有权分发，机器路径和私有配置不进入公共技能 |

这份索引用于选择已有能力，不会自动调用、安装或升级它们，也不表示所有客户端都有同名技能。产品专用流程中的私人引用不作为公共技能的隐含依赖。

## 接入、更新与回退

按 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)，技能以 `SKILL.md` 为入口，可附带界面元数据；Codex 的项目发现目录是 `.agents/skills`。本仓库的普通 `skills/` 目录仅供创作，**本次未安装、注册或启用**。其余客户端的发现路径与元数据支持需分别核验，不能据文件格式宣称已经兼容。

获准试用时，先确认许可与项目采用范围，固定完整提交 SHA，只选所需技能并保留目标已有规则；复制完整技能文件夹到目标客户端认可的位置前，检查同名项并备份，不能覆盖或累积同名技能。先测试明确调用，再用有代表性的自然请求检查是否误触发；读取成功与行为有效分开验收。跨用户分发若需插件包装，另立明确任务，不在此处加入安装器或连接器。

更新时人工比较固定版本的内容与触发描述，重新检查 [边界案例](review-cases.md)。回退只恢复获准修改的技能目录/注册项及原引用，不改变账号、模型、记忆或项目代码；已经产生的产品改动另按项目恢复方案处理。没有自动更新任务。

## 还缺什么

- **实际行为评估**：目前只有作者的合成案例走查；尚未验证自动选择、跨客户端加载，也没有独立盲测或真实项目的前后对照。优先用获准的 Web 与原生代表性任务评估，而非增加技能数量。
- **针对性无障碍验收**：正文已有检查边界，但没有完整 WCAG 审计器或原生辅助技术运行证据；正式符合性声明不能由这两个技能替代。
- **Token 与组件交接验证**：正文已有方法，尚无针对真实导出格式、变量绑定和代码组件映射的自动检查；需先获得具体输入与范围，再判断是否值得单独做技能。
- **许可与分发**：原创内容的统一许可、独立复核和正式发行仍未完成；没有添加第三方资产包、字体包或 SDK 文件。

本轮不创建这些未验证能力的空壳技能，不改旧项目和已安装技能。
