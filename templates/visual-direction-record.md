# 视觉方向记录（可选附页）

分类：`TEAM_RECOMMENDATION`；填写的具体方向与数值为 `PROJECT_CHOICE`。用于跨轮比较、交接或保留有争议的视觉决定。附在 [设计 brief](design-brief.md) 或项目现有设计记录之后，引用已有字段，不重复整份 brief；局部小修可只写受影响行。

| 字段 | 记录什么 |
| --- | --- |
| 基准与范围 | brief、设计真相源及版本；探索/局部润色；保留项、获准改动与决定人 |
| 受众、任务与气质 | 使用情境、主要任务、希望传达的感受；把形容词对应到可见选择 |
| 文字角色 | 标题、正文、标签、辅助信息和数值如何区分；批准的字体/token、语言及待查回退 |
| 颜色角色 | 内容、背景、操作、状态与品牌的关系；现有 token 与主题约束 |
| 密度与节奏 | 需要同时比较的信息；组内/组间关系、扫描顺序、滚动与文字放大的代价 |
| 识别特征 | 值得保留的特征及其用途；可以沿用已有设计，不为独特性强造装饰 |
| 取舍 | 为什么选择；什么不变；替代方向、代价和会改变选择的证据 |
| 对照条件与结果 | 相同内容、任务、视口、主题、初始状态；改动变量；画面事实、偏好、理解、任务结果分列 |
| 未决与停止 | 未验证的语言、字体、状态、平台；何时需要决定人或更多证据，何时结束 |

## 合成填写示例：继续阅读列表

此例延续主 brief 的阅读工具情境，只用于讨论；不是已批准产品设计或测试结果。

- 基准：Web 合成页面；主要任务是从列表找到上次阅读位置，打开并返回。保留条目顺序、完整标题、进度、按钮文案、系统字体、蓝色操作含义和打开/返回行为；只调整排版、间距及主次强调。
- 气质：安静、便于接续；通过较清楚的文章标题、收敛的辅助信息和稳定的对齐表达，不靠删内容制造空旷感。
- 文字与颜色：标题负责识别条目，进度负责定位上下文，操作负责接续；颜色保留原语义，同类信息用同类样式。具体 token 由实现记录；不把示例值写成通用规范。
- 密度：上次阅读条目的操作更明确，其余条目仍可打开；组内信息靠近，条目间留出区分。代价可能是行高或页面长度增加，应实看窄屏与长标题。
- 识别特征：保留“上次阅读”与章节进度的组合；不增加装饰性封面或统计卡片。
- 对照：以同一份内容与 HTML/行为，比较原样式和候选样式。先列可见变化，再分别观察偏好、能否正确说出下一步和是否完成打开/返回。没有参与者就不填写偏好或理解通过；自动点击通过不代表人的查找速度提高。
- 停止：实际画面与所测路径没有发现新阻碍后，交给决定人评议；不把演示接受为真实项目采用，不用自评分声称审美提高。
